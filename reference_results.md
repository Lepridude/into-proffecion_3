## Вопрос 5: расчёт полного ABC-XYZ-сегмента

Официальная документация Loginom Silver Kit указывает переменные границ XYZ по умолчанию X = 10%, Y = 25%. Официальная методика Loginom определяет коэффициент вариации через стандартное отклонение с делителем n. См. документацию компонента XYZ: https://github.com/loginom/loginom-silver-kit/blob/master/docs/xyz-analysis.md, официальный пример ABC-XYZ: https://examples.loginom.ru/abc-xyz-analysis/ и описание XYZ в Loginom Wiki: https://wiki.loginom.ru/articles/xyz-analysis.html.

На публичном зеркале данных применены границы ABC 80/95 и XYZ 10/25. Для периода 01.05.2019–31.10.2019 восстановлена классификация по выгрузке из 347 736 транзакций. В сохранённой полной XYZ-выгрузке стороннего проекта 3 627 товаров отсутствуют: она была рассчитана выборочным стандартным отклонением, которое не возвращает значение для единственного наблюдения. По формуле Loginom для товара с одним наблюдением коэффициент вариации равен нулю (группа X). После такой нормализации:

| Показатель | Значение |
|---|---:|
| Товаров с ABC в полном периоде | 30 566 |
| Товаров в полной XYZ-выгрузке зеркала | 26 939 |
| Товаров, отсутствующих в этой XYZ-выгрузке | 3 627 |
| Товаров с сегментом в обоих периодах после восстановления X | 21 767 |
| Товаров с изменившейся составной парой ABC-XYZ | **7 616** |

Если исключить 3 627 единичных наблюдений из полного периода, сравнение оставшихся 20 463 общих товара даёт 7 417 изменившихся сегментов. Поэтому **7 616 — расчётный ориентир по формуле Loginom, а не подтверждённый запуск компонента Silver Kit**. Окончательное значение следует сверить с экспортом компонента в Loginom, если внутренняя обработка единичных наблюдений отличается.

В стороннем ноутбуке также приведено число **3 444** товаров, сменивших только ABC-группу. Оно не является ответом на вопрос о полном ABC-XYZ-сегменте.

## Ограничения

Это сторонняя публичная копия и расчёты по её файлам, а не запуск личного исходного LGD в Loginom пользователя. Совпадение нескольких независимых контрольных показателей делает источник высоковероятно тем же учебным набором, но не доказывает, что исходный файл с учебного сервера был непосредственно открыт.

Вопрос 4 (число товаров со средней простой ценой не более 10 руб. по всем 26 месяцам) пока не подтверждён: в зеркале нет полного исходного транзакционного CSV за весь период. Скрипт analysis.py может рассчитать его по полному CSV-экспорту из Loginom. Настоящий пакет LGP в чате не запускался и не сохранялся.
