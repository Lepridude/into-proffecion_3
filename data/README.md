# Исходные данные

Поместите сюда CSV-экспорт транзакций из Loginom. Обязательные поля: `Клиент`, `Товар`, `Дата продажи`, `Кол-во`, `Сумма`.

Для задания 5 нужны два CSV-экспорта результатов ABC-XYZ из Loginom Silver Kit: полный период и последние шесть месяцев. В каждом файле необходимы поля `Товар`, `Группа ABC`, `Группа XYZ`.

Исходный `transactions_diy.lgd` отсутствовал в переданном архиве методички. Не публикуйте персональные данные покупателей.
