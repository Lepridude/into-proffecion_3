# Исходные данные

`analysis.py` принимает CSV-экспорт транзакций из Loginom. Поддерживаются английские поля `trDte`, `bcode`, `clientID`, `item`, `itemGroup`, `quantity`, `amount` и русские названия `Дата продажи`, `Код чека`, `Клиент`, `Товар`, `Группа товара`, `Кол-во`, `Сумма`.

Для вопроса 5 нужны два экспорта штатного компонента ABC-XYZ из Loginom Silver Kit: за полный период и за 01.05.2019–31.10.2019. В каждом экспорте должны быть поля товара, группы ABC и XYZ. Сравниваются только товары, присутствующие в обоих периодах.

В этой папке не содержится исходный `transactions_diy.lgd` или CSV транзакций. Не добавляйте в публичный GitHub-репозиторий необезличенные данные клиентов или учебные файлы, если преподаватель не разрешил публикацию.
