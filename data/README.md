# Исходные данные

Скрипт analysis.py принимает CSV-экспорт транзакций из Loginom.

Поддерживаемые английские столбцы исходного набора: trDte, bcode, clientID, item, itemGroup, quantity, amount. Поддерживаются и русские названия: Дата продажи, Код чека, Клиент, Товар, Группа товара, Кол-во, Сумма.

Для вопроса 5 нужны два экспорта результатов штатного ABC-XYZ из Loginom Silver Kit: полный период и 01.05.2019–31.10.2019. В каждом должны быть поля товара, группы ABC и группы XYZ.

Не добавляйте в публичный GitHub репозиторий необезличенные клиентские данные и исходные файлы курса, если они не разрешены правилами преподавателя.
