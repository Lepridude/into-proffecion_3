## 1. Подготовка

1. Откройте Loginom на учебном сервере или на доступном учебном демо-сервере.
2. Создайте новый пакет `АрхангельскийДанила.lgp`.
3. Импортируйте `/data/transactions_diy.lgd` стандартным компонентом **Импорт → LGD-файл** (в мастере выберите файл `transactions_diy.lgd`). Это специальный формат Loginom; не пытайтесь открыть его как CSV или SQLite.
4. В параметрах исходного узла задайте внутренний модификатор доступа, чтобы на тот же набор можно было ссылаться из других модулей.
5. Проверьте структуру и откройте быстрый просмотр. В датасете ожидаются поля даты, кода чека, клиента, товара, товарной группы, количества и суммы.

## 2. Модуль «Топ продаж»

1. Добавьте модуль `Топ продаж`.
2. После источника создайте узел **Группировка** по полю `Товар`.
3. Для `Кол-во` и `Сумма` задайте агрегацию **Сумма**.
4. Добавьте **Сортировку** по сумме продаж по убыванию.
5. Добавьте **Фильтр строк** и оставьте первые N строк.
6. Создайте управляющую переменную `N` целого типа со значением по умолчанию 5 и свяжите её с лимитом фильтра.
7. Сверните группировку, сортировку и фильтр в подмодель `Топ N товаров`. Добавьте выходной табличный порт и входной порт переменных.
8. Для последних шести месяцев отфильтруйте исходные данные в диапазоне **01.05.2019–31.10.2019** и передайте их в подмодель узлом **Выполнение узла**. Не клонируйте сам расчёт.

## 3. Модуль «ABC-XYZ-анализ»

1. Добавьте модуль `ABC-XYZ-анализ` и узел-ссылку на исходный набор.
2. Подключите пакет `loginom_silver_kit.lgp` из `/libs/silver_kit/`.
3. В компоненте ABC задайте объект `Товар`, показатель `Сумма`; оставьте границы накопительной доли A/B равными **80%/95%**.
4. В компоненте XYZ задайте объект `Товар`, показатель `Кол-во`; используйте штатную классификацию Silver Kit, не заменяя её самодельными порогами.
5. Объедините результаты внутренним соединением по `Объект`, чтобы оставить товары, представленные в обоих анализах.
6. Переименуйте поля в `Товар`, `Группа ABC`, `Группа XYZ`.
7. Сверните три узла в подмодель `ABC-XYZ-анализ`.
8. В визуализаторе **Куб** задайте ABC как строки, XYZ как столбцы, товар как факт.
9. Повторите расчёт для 01.05.2019–31.10.2019. Для сравнения оставьте только товары, присутствующие в обоих периодах.

## 4. Модуль «Разведочный анализ данных»

1. Добавьте модуль `Разведочный анализ данных` и узел-ссылку на источник.
2. Для `Кол-во` и `Сумма` откройте статистику, медиану, межквартильный размах и диаграммы размаха.
3. Для анализа клиентской активности сгруппируйте по клиенту и просуммируйте `Кол-во` и `Сумма`.
4. Число визитов клиента определяйте количеством уникальных календарных дат покупки, а не количеством строк/чеков.
5. Для цены сначала исключите строки с `Кол-во = 0`, затем рассчитайте `Цена = Округлить(Сумма / Кол-во; 2)`.
6. Для простой средней цены сгруппируйте по товару и усредните поле `Цена`.
7. Для средневзвешенной цены используйте `Σ(Цена × Кол-во) / Σ(Кол-во)`.

## 5. Контроль

Сверьте результаты с `reference_results.md` и контрольными значениями `report.md`. В частности, исходный набор имеет около 1,01 млн строк; средняя сумма транзакции близка к 623,2 руб.; максимум суммы чека — 213 177 руб.; максимум количества — 1 100; одна запись имеет нулевое количество.

## 6. Сохранение

1. Убедитесь, что пакет содержит все три модуля.
2. Сохраните пакет как `АрхангельскийДанила.lgp`.
3. Экспортируйте два результата ABC-XYZ (полный период и последние шесть месяцев), каждый с полями `Товар`, `Группа ABC`, `Группа XYZ`.
4. При наличии CSV-экспорта транзакций и двух экспортов сегментов запустите `analysis.py` для независимой проверки вопросов 1–5.
5. Поместите `.lgp` и итоговые экспорты в этот репозиторий, если они разрешены правилами курса и не содержат персональных данных.
