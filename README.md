## Подтверждённые результаты

По публичной контрольной копии, совпадающей с методичкой по нескольким независимым контрольным характеристикам, подтверждены вопросы 1–3:

- 401 клиент с расходами не более 100 руб. за период;
- средние суммарные расходы одновизитного клиента — 3 535,45 руб. (округлённый ответ — 3 535 руб.);
- 275 клиентов с более чем 50 уникальными календарными датами покупок.

Вопрос 4 требует полного CSV транзакций; вопрос 5 — двух CSV-экспортов результатов штатного ABC-XYZ Silver Kit. Скрипт для цен исключает только строки с `quantity = 0`, как указано в методике. Дополнительная публичная сверка дала предварительную оценку 7 345 изменений ABC-XYZ при выборочном стандартном отклонении, но она не считается ответом: официальная формула Loginom использует делитель `n`, а полнопериодная выгрузка не содержит числа наблюдений по каждому товару. Значения 248 и 7 616 также не подтверждены. Подробности — в `reference_results.md`.

## Запуск расчётов

```bash
python3 -m pip install -r requirements.txt
python3 analysis.py data/transactions.csv
```

Для сравнения сегментов полного периода и последних шести месяцев:

```bash
python3 analysis.py data/transactions.csv \
  --segments-all data/abcxyz_all.csv \
  --segments-6m data/abcxyz_6m.csv
```

Поддерживаются русские имена полей и английские имена исходного набора `trDte`, `clientID`, `item`, `quantity`, `amount`.

## Проверка скрипта

Запуск регрессионных тестов:

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
```

Тесты проверяют расчёты клиентских метрик, учёт визитов по уникальным календарным датам, исключение нулевого количества при расчёте цены и сравнение полной пары ABC-XYZ только для общих товаров. Некорректные выгрузки с пустыми значениями или дублирующимися товарами отклоняются.
