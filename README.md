## Состав проекта

- report.md — отчёт по методичке: три модуля Loginom, контрольные данные, индивидуальные расчёты и ограничения.
- INSTRUCTION.md — последовательность сборки пакета Loginom и его модулей.
- reflection3.md — рефлексия по пяти вопросам.
- reference_results.md — числовые результаты, подтверждённые на зеркале того же транзакционного набора, и происхождение данных.
- analysis.py — расчёты вопросов 1–5 по CSV-экспорту Loginom; поддерживает русские и английские названия полей.
- requirements.txt — зависимости Python.
- data/README.md — формат входных файлов и правила хранения данных.

## Запуск расчётов

```bash
python3 -m pip install -r requirements.txt
python3 analysis.py data/transactions.csv
```

Для сравнения ABC-XYZ-сегментов:

```bash
python3 analysis.py data/transactions.csv \
  --segments-all data/abcxyz_all.csv \
  --segments-6m data/abcxyz_6m.csv
```

Исходный CSV может содержать русские имена столбцов или стандартные имена trDte, clientID, item, quantity, amount.

## Подтверждённые показатели

По публичной контрольной копии набора, совпадающей по ключевым контрольным характеристикам из методички, подтверждены:
- 401 клиент с суммарными расходами не более 100 руб.;
- средние суммарные расходы одного одновизитного клиента — 3 535,45 руб. (ответ после округления — 3 535);
- 275 клиентов с более чем 50 визитами;
- всего 12 859 одновизитных клиентов.

По публичной контрольной копии также рассчитан ориентир **7 616 товаров со сменившейся полной парой ABC-XYZ** при документированных настройках Loginom XYZ X=10%, Y=25%. Этот показатель требует сверки с фактическим компонентом Silver Kit из-за обработки единичных наблюдений.

Подробности, источники и ограничения сопоставления приведены в reference_results.md.

## Ограничения выполнения

Точное число товаров со средней простой ценой не более 10 руб. (вопрос 4) не подтверждено: в доступной копии нет полного набора транзакций за все 26 месяцев. Среда Loginom не подключена к этому чату, поэтому настоящий пакет .lgp не выдаётся за созданный. Скрипт analysis.py подготовлен для воспроизведения вопросов 1–5 по CSV-экспортам.
